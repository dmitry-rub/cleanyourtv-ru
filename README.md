# Clean Your TV RU

Неофициальная русская сборка [Clean Your TV](https://github.com/udhaykumarbala/cleanyourtv-app)
(MIT) для Android TV. Оригинальный код приложения не менялся: переведены
ресурсы и добавлена возможность пополнять список моделей ТВ.

## Что внутри

- русский интерфейс (1176 строк + 2 plurals);
- 173 профиля ТВ, 47 брендов;
- автоматический и ручной режимы чистки;
- отключение пакетов, а не удаление: всё обратимо;
- своя подпись, поэтому обновления ставятся только из этого репозитория.

## Установка

1. Скачай APK из [Releases](../../releases/latest).
2. Если стоит официальная версия Clean Your TV — сначала удали её:
   подписи разные, поверх установить нельзя.
3. Установи APK и разреши установку из этого источника.

## Обновления

Через [Obtainium](https://github.com/ImranR98/Obtainium): добавь репозиторий

```
https://github.com/dmitry-rub/cleanyourtv-ru
```

Obtainium будет следить за релизами и обновлять приложение сам. Данные
при обновлении сохраняются.

## Ограничения

- только Android TV; Samsung Tizen, LG webOS и Roku не поддерживаются;
- это не официальная сборка: вопросы по переводу — не к авторам оригинала;
- обновления из самого приложения (кнопка «Проверить обновления») ведут на
  апстрим и не установятся из-за другой подписи — используй Obtainium.
